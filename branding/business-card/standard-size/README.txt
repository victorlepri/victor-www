STANDARD SIZE BUSINESS CARD
==============================

Canvas at 300 dpi
  bleed  3.66 by 2.16 inches
  trim   3.50 by 2.00 inches
  safe   3.34 by 1.84 inches

The supplied InDesign template is included as template.idml for placement and final shop checks.
The SVG files are editable vector masters. The PNG files are raster proofs. The two page PDF is front first and back second, with the bleed included. print-high-quality.pdf is the combined vector version for final printing. front-high-quality.pdf and back-high-quality.pdf are separate vector print files. print.pdf is the raster proof.

The background and pink rule run through the bleed, with the pink edge continuing 24 pixels inside the trim so it survives cutting. All name, mark, slogan, contact, and site elements sit 16 pixels inside the safe area for print breathing room.

Front: ART IS TECHNOLOGY
Back: TECHNOLOGY IS ART
